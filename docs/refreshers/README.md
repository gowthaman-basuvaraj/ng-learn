| 04 | [Dependency injection](04-dependency-injection.md): injector tree, providers, `inject()`, the "context" pattern | day 2 |

| 06 | [Change detection](06-change-detection.md): zone.js vs zoneless, OnPush, signals, gotchas | day 2, **must know** |
| 07 | [Routing](07-routing.md): config, lazy loading, functional guards, params gotcha, URL state | day 3 |
| 08 | [Forms](08-forms.md): typed reactive forms, validators, dynamic controls, server errors, CVA | day 3 |
| 09 | [State management](09-state-management.md): signal services, NgRx SignalStore, classic NgRx (Redux mapping) | day 3 |
| 10 | [Realtime](10-realtime.md): WebSocket vs SSE, one connection → store → many signals, resilience checklist | day 3 |
| 11 | [Testing](11-testing.md): TestBed, component/HTTP/store tests, [testing RxJS](11-testing.md#testing-rxjs) (fake timers, Subjects, marbles), what's worth testing | day 4 |
